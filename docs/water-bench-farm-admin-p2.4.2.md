# P2.4.2 Farm Admin Web operations
Existing farm-admin-only /water-bench route. Scoped kiosk and calibration listing, station registration/revocation, versioned schedule update, calibration list/revoke/QC/create (technical JSON, not a guided optical wizard), initial manual or complete scheduled batch inference, exact per-channel retry, explicit retest, provenance/NH3 reference. No hardware dispatch or official chemical publication endpoint. Request bodies for assessments/retest/ammonia are retained in sessionStorage per user+area+batch+analyte before submission; retry only with original ID/body. Closing tab can lose request; do not silently mint a new retry. Existing BE prevents duplicate assessment and cross-area access. Salinity measurement ID and calibration image IDs currently entered manually, validated by BE; guided pickers and multi-device UX still pending. CI tests cover local payload validation, not browser E2E or physical verification.
